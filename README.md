# Exercícios de Classes e Métodos em Java

Repositório com 50 exercícios práticos de Programação Orientada a Objetos em Java, focando em classes, atributos, métodos com retorno, métodos `void` e passagem de parâmetros (tipos primitivos e por referência).

## Estrutura do Projeto

Os arquivos estão organizados no pacote `exer.classes_metodos`:

```text
src/
└── exer/
    └── classes_metodos/
        ├── dominio/   # Classes principais de domínio (sem static)
        └── test/      # Classes de teste com o método main
```

## Conteúdo dos Exercícios

1. **Parte 1 (1–10):** Criação de classes, atributos e instanciação de objetos (`Estudante`, `Professor`, `Carro`, `Produto`, `Livro`, `Celular`, `ContaBancaria`, `Animal`, `Filme`, `Aluno`).
2. **Parte 2 (11–20):** Métodos com retorno (`return`).
3. **Parte 3 (21–30):** Métodos com passagem de parâmetros.
4. **Parte 4 (31–40):** Métodos `void` e classes utilitárias de impressão.
5. **Parte 5 (41–50):** Passagem de objetos (tipo de referência) como parâmetro e integração simples de sistema.

## Como Executar

1. Abra o projeto no IntelliJ IDEA (ou outra IDE Java).
2. Navegue até `src/exer/classes_metodos/test/`.
3. Execute qualquer classe `*Test*.java` desejada clicando no botão **Run** ao lado do método `main`.
